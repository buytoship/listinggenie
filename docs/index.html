ListingGenie — Live Demo

Turn rough notes into an Etsy/eBay-ready listing: 3 title variants (≤140 chars), 13 tags (≤20 chars each), a structured description, and an Etsy fee / pricing tip.

This page runs the deterministic fallback engine in your browser. The full app (source on GitHub) drafts copy with a local open-weight model via Ollama when one is available — no API key, no per-token cost.
